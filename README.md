# Weather App

A responsive weather application that fetches live conditions for a city from a weather API and presents them in a clean, Bootstrap-styled interface.

## Features

- Search current weather by city name
- Live data from a weather API (temperature, conditions, humidity, wind)
- Responsive layout built on Bootstrap

## Run it

No build step — open the page in a browser, or serve the folder locally:

```bash
cd "weather app"
python3 -m http.server 8000
# visit http://localhost:8000
```

If you fork this, add your own weather-API key in the JavaScript config before requesting data.

## Tech

Vanilla JavaScript · Bootstrap · HTML · CSS
